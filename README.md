Message Board

A simple message board built using Node.js. This app allows users to view default messages and add new ones via a form submission.

Features

Display a list of default messages.

Add new messages via a simple form.

Built with Node.js and Express.

Installation
Prerequisites

Node.js (v12.x or later)

npm (Node Package Manager)

Steps to Set Up

Clone the Repository:

git clone https://github.com/sample-maxx/messageBoard.git


Navigate to the project directory:

cd messageBoard


Install Dependencies:
Ensure you have all the required packages installed.

npm install express
npm install ejs

Run the Application:
Start the Node.js server.

npm start


The application will be available at https://messageboard-production-ac45.up.railway.app/
.

Usage

Upon visiting the app, you will see a list of default messages.

To add a new message:

Fill out the form with your message.

Submit the form to see your message added to the list.

Dependencies

Express: Web framework for Node.js to handle routing and HTTP requests.

Body-Parser: Middleware to parse incoming request bodies.

EJS: Templating engine used to render the dynamic content in views.
